# 全套汇总总结
## 一、两种启动U盘
1. **微软原版安装启动盘**
制作：MediaCreationTool / Rufus，直接写入系统引导
内容：自带Windows官方安装程序
用途：开机直接进入蓝色安装界面，只能安装原版系统
优点：纯净，和你虚拟机练习界面一致
缺点：没有维护工具，不能备份文件、清除密码、修硬盘

2. **微PE启动盘（维护盘）**
PE=Windows预安装环境，是跑在内存里的精简迷你Windows
制作：微PE工具箱写入U盘；**PE本身不带系统**
需要额外操作：自己把Windows ISO镜像复制到U盘可见分区（ISO不用解压，只是一个存放的文件）
用途：先进入迷你Windows桌面，维护优先，顺带装系统
桌面自带工具：此电脑、Windows密码修改（NTPWEdit）、DG分区工具、WinNTSetup（Windows安装器）、Dism++、硬盘检测工具
优点：可以提前备份C盘文件、清除本地账户密码、分区调整、硬盘检测、修复系统
缺点：需要自己准备ISO镜像

> 区分：原版盘=直接装系统；PE盘=维修工作台，ISO是单独放U盘里的系统安装包

## 二、PE使用流程（华硕无畏16）
1. U盘插电脑，关机，开机立刻按F8，启动菜单选UEFI开头的U盘，进入PE桌面
2. 常用操作
- 备份文件：打开此电脑，把C盘重要资料复制到D盘/U盘
- 清除密码：打开Windows密码修改工具，选中本地账户，清空密码，保存更改，重启拔U盘
  ✅仅本地账户有效；微软账号密码存在云端，PE清不掉；BitLocker加密硬盘无法操作
- 重装系统（两种方式，都属于重装）
  ① WinNTSetup（Windows安装器）：PE专用工具，读取ISO里的wim文件，释放系统，速度快
  ② setup.exe：挂载ISO后运行，就是虚拟机里熟悉的官方安装向导
  ⚠️全新重装：选择自定义安装，删除旧C盘分区，C盘文件全部清空；D盘文件保留
  ⚠️升级安装：保留原有文件、软件、账户密码
3. 重装第一次重启**一定要拔掉U盘**，否则会再次进入PE

## 三、账户区分
- 本地账户：账号密码信息存在电脑硬盘SAM文件里，离线可登录；PE工具可以清空密码，重装系统后旧账号直接消失
- 微软账户：账号密码存在微软云端服务器；PE无法清除；重装只是本机不再保存这个账号，云端密码不变

## 四、核心注意事项
1. PE运行在内存，**不主动格式化、删除分区，不会自动删除硬盘里的数据**
2. 引导和分区匹配：UEFI启动对应GPT分区；Legacy启动对应MBR，不要混搭
3. 不要修改、删除U盘隐藏引导分区，只操作U盘可见分区
4. 网上老毛桃、大白菜等PE捆绑广告，优先使用微PE
5. 法律提醒：仅操作自己的设备，不要解锁别人电脑
6. 概念分清：**重装系统是整件事；Windows安装器只是PE里面用来重装的其中一个工具**

## 极简口诀
原版U盘直接装，功能单一很清爽；
微PE是维修台，ISO单独放U盘；
本地密码本地存，PE清空不用慌；
微软账号云上放，PE拿它没良方；
全新重装清C盘，升级安装文件藏。
