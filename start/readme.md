准备物品

1. U 盘：8GB 及以上，U 盘里所有文件会全部清空，提前备份

2. 一台能正常上网的 Windows 电脑（用来制作启动盘）

> ⚠️ 优先用微软官方工具（就是刚才你打开的这个 `MediaCreationTool`），无捆绑，纯净原版



第一步：制作 U 盘启动盘（MediaCreationTool）
1. 去微软官网下载【Windows10 介质创建工具 MediaCreationTool22H2.exe】
2. 插上 U 盘，右键管理员运行这个工具
3. 跟着向导：
- 接受许可条款
 - 选择：为另一台电脑创建安装介质（U 盘、DVD 或 ISO 文件）
 - 语言、版本、体系结构：一般勾选【对这台电脑使用推荐的选项】，也可以自己手动改成 Win10 专业版 64 位
- 介质选择：U 盘（这次就不是 ISO 文件了）
- 选中你的 U 盘，下一步
4。 工具自动下载系统、写入 U 盘，等待完成，不要中途拔 U 盘。



> 完成之后这个 U 盘就是原版 Windows 安装启动盘

1. 选 U 盘之后，联网状态下它会自动下载 Win10 22H2 原版系统文件
流程：

- 选【为另一台电脑创建安装介质】
- 选语言 / 版本 / 架构（默认推荐就行）
- 介质类型选【USB 闪存驱动器】
- 选中你的 U 盘 → 下一步
👉 然后：自动从微软服务器下载系统包 → 校验文件 → 自动格式化 U 盘 → 写入成启动盘，全程不用提前准备 ISO 镜像


第二步：电脑开机，调出启动菜单，从 U 盘启动

1 把做好的 U 盘插到要装系统的那台电脑的 USB 口（优先 USB2.0 口，兼容性更好）

2 开机，立刻连续按启动菜单快捷键，不同品牌不一样：



表格



| 品牌 | 启动热键 |

| --- | --- |

| 华硕笔记本 / 台式 | F8 |

| 联想 | F12 |

| 惠普 | F9 |

| 戴尔 | F12 |

| 微星、七彩虹主板 | F11 |

| 技嘉主板 | F12 |

| 台式组装机通用 BIOS | Del |

3\. 在蓝色 / 黑白启动菜单里，选择你 U 盘的名字（一般带 `USB HDD`、U 盘品牌名），回车



> 

> ✅ 成功的话，就进入你刚才虚拟机一模一样的 Windows 安装界面！



> 

> 如果按热键调不出启动菜单：就要进 BIOS（F2/Del），把 U 盘放到第一启动项，保存重启。



\## 第三步：后面的安装，和你虚拟机完全一样



依次：



1\. 语言、时区、键盘 → 下一步，现在安装

2\. 密钥页：点【我没有产品密钥】

3\. 版本：选 Windows10 专业版

4\. 安装类型：\*\*自定义：仅安装 Windows（高级）\*\*

5\. 磁盘分区页面（就是你现在这个界面！）

&#x20;  - 全新空白固态：选中未分配空间，新建，设置 C 盘大小，系统自动生成 EFI、MSR 分区

&#x20;  - 如果硬盘里有旧分区：\*\*全部选中分区点删除\*\*，变成整块未分配空间再新建分区（⚠️ 删除分区 = 数据全部消失！）

6\. 选中 C 盘分区，下一步，开始复制系统文件安装



\## 第四步：系统装好之后（虚拟机不需要，真实电脑必须做）



系统部署完成，进入桌面之后第一件事：\*\*装驱动\*\*



1\. 不要用第三方驱动精灵这类工具（捆绑软件多）

2\. 笔记本：去该品牌官网 → 支持服务 → 输入你的电脑序列号，下载对应型号网卡、显卡、声卡、芯片组驱动

3\. 台式组装机：主板官网下芯片组、网卡声卡；显卡官网下显卡驱动

\*\*驱动 = 硬件和 Windows 之间的翻译官\*\*

硬件（网卡、显卡、声卡、触摸板）本身不懂 Windows 的指令，Windows 也看不懂硬件，驱动就是中间翻译，让它们能对话。



举几个例子：



\- \*\*网卡驱动\*\*：没有它 → 电脑上不了网，WiFi、网线都识别不到

\- \*\*显卡驱动\*\*：没有它 → 画面模糊、分辨率很低、没法开高刷、游戏 / 绘图卡顿

\- \*\*声卡驱动\*\*：没有它 → 电脑没声音

\- \*\*芯片组驱动\*\*：主板基础驱动，管理硬盘、USB 接口，缺了会有 USB 不稳定、硬盘异常

\- \*\*触摸板、摄像头、快捷键驱动\*\*：笔记本专属，缺了触摸板失灵、Fn 快捷键无效





\## 补充两个高频踩坑点



1\. \*\*BIOS 里面的模式：UEFI（推荐，就是我们现在虚拟机 EFI 启动这种）\*\*



> 

> ⚠️ 启动盘、BIOS 启动模式、硬盘分区表三者必须匹配，不然启动失败

&#x20;  - UEFI 模式：硬盘分区表是 GPT，就是现在这种，自动生成 100M EFI 引导分区；现在新电脑默认都是 UEFI

&#x20;  - Legacy 传统模式：老模式，分区表 MBR，没有 EFI 分区，现在新机很少用

2\. U 盘启动黑屏 / 识别不到 U 盘

&#x20;  - 换 USB2.0 接口、换 U 盘、重新制作启动盘；

&#x20;  - BIOS 里关闭安全启动（Secure Boot），部分主板原版 Win10 可以开，有些会拦截



\## 和你刚才操作的对比总结



\- 虚拟机：ISO 镜像 → 挂载到虚拟光驱启动

\- 真实电脑：ISO 写入 U 盘 → 主板 USB 启动，后续安装界面、分区逻辑完全相同







**普通启动盘**（Rufus、微软 Media Creation Tool、软碟通）：不用你手动提前清空，点开始制作的时候，工具会自动全盘格式化、全部清空 U 盘里所有文件！\*\*



> 

> ⚠️ 重要：重要文件一定要提前备份走！格式化删除之后很难恢复



\### 分两种情况说清楚



1\. Rufus / 微软官方工具 / 微 PE（最常用）



\- 不用你自己先去格式化 U 盘；

\- 一旦点【开始】，工具自动重写分区表、格式化，U 盘里所有东西全部删掉；

\- 哪怕 U 盘里还有很多文件，直接就抹掉。



2\. Ventoy（多镜像启动盘，这个特殊一点）



\- 第一次安装 Ventoy 到 U 盘的时候，依然会清空全盘；

\- 装好 Ventoy 之后，以后往 U 盘复制 ISO 镜像、存普通文件，\*\*不会再清空\*\*，可以同时当普通 U 盘存资料，这是它的优势

避坑提醒



\- 不要赌 “会不会保留文件”，只要里面有你要的资料先复制到电脑里备份，最稳妥；

\- 不要选错磁盘！Rufus 选错会把电脑硬盘格式化。





Rufus

📦 准备材料



1\. U 盘：≥8GB，优先 USB3.0；⚠️ U 盘里面所有文件会全部清空，重要资料先备份走

2\. Windows 原版 ISO 镜像（Win10/Win11 都可以）

3\. Rufus：官网 `rufus.ie` 下载，\*\*免安装，直接双击打开



📝 步骤

1. 插上 U 盘，双击打开 Rufus

2. 设备：下拉框，仔细核对，选中你的 U 盘（这一步最容易翻车，选错会格式化电脑硬盘！看容量判断）

3. 引导选择：选「磁盘或 ISO 镜像」，点右边【选择】，选中你下载好的 `.iso` 系统镜像

4. 分区方案（重点）
- ✅ 2013 年后新机、你的华硕无畏 16 锐龙版：GPT + UEFI（非 CSM）（推荐）
- 老电脑（Win7、很老台式）：MBR + BIOS（或 UEFI-CSM）

5. 下面的【文件系统、簇大小、卷标】全部默认不动，不用改
6. 镜像选项：默认「标准 Windows 安装」
7. 确认全部设置无误，点右下角【开始】
8. 弹出警告：此 U 盘上全部数据将被销毁，确认没错，点【确定】
9. 等待进度跑完，到 100%、状态显示就绪，就做好了，直接安全弹出 U 盘


⚠️ 重要避坑

1. 一定确认【设备】是 U 盘，不是电脑硬盘！
2. 做好之后，电脑开机启动：开机立刻按启动热键（华硕笔记本一般是 F8），在启动菜单里，选带 `UEFI:` 开头的 U 盘启动项
3. 如果做好后无法引导：大概率 GPT/MBR 选错了，换另一种分区方案重做
4. 这个 U 盘做好后，不能直接再往里存普通文件（Ventoy 才可以）

补充：启动菜单快捷键参考
